# Guides

Set omnia-llm up on your machine, run it, and use it from Omnia.

1. **Pick your machine:** [Mac](apple.md) · [NVIDIA GPU](nvidia.md) · [AMD GPU](rocm.md) ·
   [CPU only](cpu.md).
2. **Connect Omnia.** Each guide ends with the values to enter; where to enter them is in
   [Omnia's guide](https://github.com/osirisQdt2810/omnia/blob/main/docs/guidance/local-server/README.md).
3. **If you need to:** [use it from other computers](remote-access.md) ·
   [change or add models](models.md).

Every guide works in a terminal opened in this repository's folder. To get it:
`git clone https://github.com/osirisQdt2810/omnia-llm`, then `cd omnia-llm`.
